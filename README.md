# Assinatura de e-mail Dotz · Black Friday

Gerador da assinatura de e-mail da Dotz para a Black Friday 2026, feito pela Mediacraft. Abra `assinatura-dotz/index.html`, preencha nome, cargo e e-mail e copie a assinatura para o Gmail.

Detalhes e como regenerar as imagens: [assinatura-dotz/README.md](assinatura-dotz/README.md).

O nome `buscador-de-imagens` é histórico. O Buscador fica em `mediacraft-cc/buscador`.
